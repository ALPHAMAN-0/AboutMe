Why there is no public link

These tools edit a shop’s real prices and stock, so this page explains how they work instead of linking to them. Each owner keeps the only login.

How the 2 tools work

Each one fits a habit the owner already had, so there was nothing new to learn.

Stock audit app

A friend needed fast stock counts in his shop without paying for inventory software. He already kept everything in a Google Sheet.

  • Search

    Find a product as you type

  • Price and count

    Set both for each item on the shelf

  • Google Sheets

    Every change writes straight to the owner’s sheet

    Storage

Invoice generator

  • One account

  • Dashboard

    Create, view and track each invoice

  • No subscription
